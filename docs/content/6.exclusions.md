---
title: Route exclusions
description: Keep health checks and selected routes available.
---

Nuxt assets and the internal status endpoint are always exempt. Add exact paths or wildcard patterns:

```ts
export default defineNuxtConfig({
  maintainer: { exclude: ['/health', '/webhooks/**', '/public/*'] },
})
```

`*` matches within one segment and `**` crosses separators. Exclusions bypass HTML and JSON guards, so keep the list narrow.
