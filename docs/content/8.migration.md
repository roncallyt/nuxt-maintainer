---
title: Migrate from nuxt-maintenizr
description: Move from build-time routing to live state.
---

1. Replace `nuxt-maintenizr` with `nuxt-maintainer`; rename config key `maintenizr` to `maintainer`.
2. Remove `.nuxtrc` flags and `/maintenance` overrides. State now lives in the configured Unstorage mount.
3. Compose `<NuxtMaintenanceError>` into the existing `error.vue`.
4. Replace old CLI commands with `npx nuxt-maintainer ...`.
5. Remove compatibility assumptions: version 1 intentionally ships no old aliases.

The new commands affect a running SSR server immediately. Test the error page and bypass in staging before switching automation.
