---
title: CLI
description: Application and section maintenance commands.
---

All commands accept `--cwd <directory>`. Successful status reads exit zero whether the target is up or down; invalid configuration and storage failures exit non-zero.

```bash
nuxt-maintainer down [--message <text>] [--retry <seconds>] [--refresh <seconds>]
nuxt-maintainer down [--secret <token> | --with-secret]
nuxt-maintainer up
nuxt-maintainer status [--json]

nuxt-maintainer section down <name> [--message <text>]
nuxt-maintainer section up <name>
nuxt-maintainer section status [name] [--json]
```

Section names are stable lowercase identifiers using letters, numbers, dots, underscores, or hyphens. `--json` is intended for automation. Site and individual-section responses contain `scope`, `status`, `down`, and any configured maintenance fields. A response for all sections contains `scope` and a `sections` object keyed by section name.
